# Generated Code

Owner of: files produced by a generator rather than written by hand.

Do not manually edit files marked `// Code generated ... DO NOT EDIT.` —
change the generator, template, schema, or source input and regenerate.

If a generated file lacks a standard marker, inspect repository conventions
before editing: a missing marker is not permission, it is an unanswered
question.

A generated file is still a contract for its consumers. Regenerating it can
change exported types, errors, and wire formats — see
[packages](packages.md) for the compatibility rules that still apply.
