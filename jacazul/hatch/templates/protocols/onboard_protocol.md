## Onboard Protocol

When user types **'onboard'**, something related, or the slang equivalent (see `GLOSSARY.md`), initialize session with complete context display:

**🚀 Session Initialized** 

**REQUIRED ACTIONS:**
1. Run the "Context Orientation" sequence of the hub (`SKILL.md`); it is the
   only list of what to run. A handoff note printed by
   `tw-flow session resume` is read before proceeding.
2. Present tactical insight following the **Response Format** rules and **STOP**.

**DO NOT auto-execute tasks - wait for user direction.**
